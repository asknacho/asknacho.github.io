# Scope of this guidance

The shared documents describe general development and review preferences. Apply them only to the code, design and requirements supplied for the current task.

Examples are fictional. Do not search for their function names or try to locate a historical implementation. Resolve details from the current review inputs.

Use DEVELOPMENT_GUIDELINES.md as the central human-readable guide, REVIEW_AGENT.md as the review prompt, and PRINCIPLES.md or principles.json for individual rules. CALIBRATION.md contains synthetic examples of review judgment.

The hidden .research directory is an archival source collection. It is outside the review scope. Do not load it, follow its links or use its identifiers to search elsewhere unless the user explicitly requests source research.

Explain concerns critically and simply, using small incremental examples. Avoid rhetorical contrasts of the form “it is not this, but this.”
